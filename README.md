# Machine Learning Internship Projects — Elevvo Pathways

Hands-on machine learning projects completed during a Machine Learning Internship with **Elevvo Pathways** (Sep–Oct 2025), covering the full applied workflow: data preprocessing, model training, evaluation, and tuning across forecasting, classification, clustering, and recommendation tasks.

## Projects

| # | Project | Problem | Approach | Result |
|---|---------|---------|----------|--------|
| 1 | [Loan Approval Prediction](./1_loan_approval) | Predict loan default risk on an imbalanced banking dataset | Compared ensemble methods and synthetic oversampling; selected a threshold-tuned Logistic Regression model for interpretability | F1-score: 0.77, Recall: 0.71 |
| 2 | [Customer Segmentation](./2_customer_segmentation) | Identify distinct customer groups for targeted marketing | Compared K-Means and DBSCAN clustering; selected K-Means for interpretability and business alignment | 5 distinct, actionable customer personas (46% disagreement rate vs. DBSCAN) |
| 3 | [Sales Forecasting](./3_sales_forecasting) | Forecast sales on time-series retail data | XGBoost pipeline, compared against a Random Forest baseline | 13.2% reduction in MAE vs. baseline |
| 4 | [Movie Recommendation System](./4_movie_recommendation) | Recommend relevant movies to users | SVD-based recommender vs. standard collaborative filtering | 160% improvement in Precision@5 |
| 5 | [Traffic Sign Recognition](./5_traffic_signs) | Classify traffic sign images into their correct class | CNN-based image classification (Keras/TensorFlow) | Additional task completed under time constraints; bonus/secondary deliverable |

Each folder contains the notebook(s), and where applicable, a short write-up of the approach and results.

## Tools & Libraries

Python, Pandas, NumPy, Scikit-learn, XGBoost, Keras, TensorFlow, OpenCV, Jupyter Notebook

## About This Work

Projects 1–4 were the core deliverables of the internship, each completed end-to-end: data cleaning, feature engineering, model selection, and evaluation against a baseline. Project 5 was an additional task selected from a list of available options and completed under a tighter deadline.
